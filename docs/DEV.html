Screenshot assets

Bake a screenshot into the README assets. 

scripts/cardify.sh <input.png> <output.webp> [radius] [border-color]

Each screenshot has two flavors — the script produces the -card one; the site uses a plain encode of the same shot.

FileUsed byFrame
foo.webpdocs/index.htmlNone — the site's CSS draws its own frame
foo-card.webpREADME.md, vscode/README.mdRounded corners + 1px border baked in — GitHub renders <img> without CSS
  • Border color #30363d — GitHub dark-theme border gray, works on light too (an earlier #8b949e + <picture> theme switch was dropped: dark-only variants with the original names won)
  • Radius ≈ 12px at display size (e.g. radius 8 on a ~166px-wide shot shown at 120px)
  • Everything outside the rounded corner is transparent
