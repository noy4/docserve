docserve

Serves a folder of HTML as a card gallery with live reload.

Download for macOS GitHub

Gallery

Card grid, iframe previews, copy-path button.

Auto reload

Changes appear instantly.

Desktop & CLI

Control it from the menu bar or the terminal.

Getting started

macOS app

1

Download

2

Launch — on the security warning, click Done (not Move to Trash), then approve via Open Anyway in System Settings → Privacy & Security

The warning appears because docserve isn't signed with an Apple Developer certificate ($99/year).

3

Pick a folder — the gallery opens in your browser

CLI

npx @noy4/docserve ~/reports --open   # serve
npx @noy4/docserve stop               # stop all

Or install globally: npm install -g @noy4/docserve — then run docserve <folder>.
