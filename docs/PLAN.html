Roadmap

Phase 8 — npm publish P2
Publish the CLI as the scoped @noy4/docserve — the unscoped docserve name is taken by an unrelated, dormant 2019 package. First release is manual; later releases run on GitHub Actions trusted publishing (OIDC, no tokens, provenance).
Package metadata
repository / homepage / bugs · publishConfig (access: public — scoped defaults to restricted — + provenance) · bin stays docserve
First manual publish
npm account + 2FA · npm pack --dry-run (13.1 kB, 9 files) · npm login → npm publish · verify npx @noy4/docserve
Trusted publishing
npmjs.com Trusted Publisher (noy4 / docserve / publish-cli.yml) · workflow with id-token: write · cli-v* tags → OIDC publish without NPM_TOKEN
README commands
switch npx docserve / npm install -g docserve to the scoped name

Verify: npx @noy4/docserve ~/reports --open serves a gallery in a clean environment · provenance badge visible on the npmjs.com package page

Phase 7 — Distribution P2
Unsigned macOS distribution: an electron-builder DMG published on GitHub Releases. No auto-update (electron-updater requires code signing), so the tray shows a "new version" notice instead. npm publish of the CLI is a separate future phase.
Packaging-ready CLI resolution
server.mjs — resolve the CLI from the dev layout / app.asar.unpacked / process.resourcesPath · keeps the docserve PATH fallback
electron-builder config
appId · files + asarUnpack for cli/ + extraResources from ../cli · LSUIElement · dmg (arm64 + x64) · identity: null + hardened runtime off
App icon
build/icon.icns from a 1024 px source · replaces the default Electron icon in Finder / installer
GitHub Release
DMG + sha256 per arch · README: install via System Settings → Privacy & Security → Open Anyway (macOS 15 removed right-click open)
Update notice
tray checks the latest GitHub Release tag → "New version available" menu item opens the release page (no in-app update)

Verify: npm run dist DMG launches via Open Anyway · tray start/stop from the installed app · Open opens the gallery

Phase 6 — Desktop app P2
macOS tray client controlling the CLI.
Electron zero-window main process
tray icon (outline when stopped / filled when running)
Start / Stop toggle
spawn the CLI · Open reads the URL from state.json
State watch
fs.watch + 2 s polling + pid liveness → menu rebuild (watch only ~/.cache/docserve/)
Change Folder…
stop → restart · remember the last folder in desktop.json
Quit & first launch
stop → app.quit() · symlink the CLI to ~/.local/bin/docserve

Verify: all menu flows, including a folder switch while running

Phase 5 — Tests P1
End-to-end tests for injection, the reload broadcast, and the CLI lifecycle.
Test suite
cli/server.test.mjs — injection · /__reload broadcast · status codes · CLI lifecycle, run with node --test
Isolation
DOCSERVE_STATE env override for the state path · random --port per run (parallel-safe)

Verify: node --test cli/ green

Phase 4 — CLI P1
Lifecycle commands: stop/status, background spawn, single-instance guard.
stop / status
SIGTERM + clear state; stale state removed silently · status exits 1 when none
--background · --open · --port
detached spawn · open the browser · fallback +1 (≤ 20 tries)
Single-instance rule
same docsDir → point at its URL · different → error prompting docserve stop
-h / -v
show help / version

Verify: start → status → stop cycle; background + open; stale state.json

Phase 3 — Live reload P0
WebSocket broadcast, fs.watch detection, and page injection.
Page injection
server/inject.mjs — reload client + copy button before the last </body> · < → \u003c escaping · iframe early-return
WS server /__reload
server/websocket.mjs — handshake · text frames · ping → pong (RFC 6455 subset)
UpdateListener
server/watch.mjs — fs.watch(docsDir, { recursive: true }) filtered to *.html · 50 ms debounce batch · known-files tracking → contentSetChanged

Verify: edit reloads its own tab only; add/delete reloads the gallery; previews never reload

Phase 2 — /api/files + gallery P0
File metadata for /api/files and the gallery UI.
File metadata
server/files.mjs — recursive *.html listing (exclude index.html) · <title> / created_at extraction (4 KB head → 1 MB fallback) · git date maps cached per repo root · sort by created desc
Gallery template
cli/index.html — card grid · lazy iframes (rootMargin: 400px, max 3 concurrent) · copy path

Verify: cards render with resolved dates; nested assets load

Phase 1 — Server core P0
The HTTP layer: docsDir validation, URL mapping, MIME, status codes, and the state file.
Scaffold cli/
package.json (name, bin, type, files, engines) · bin.mjs stub · server/index.mjs
docsDir resolution + validation
missing → exit 1
URL mapping
/, /index.html → gallery template · raw static files · MIME map · 400 / 403 / 404
Runtime state
server/state.mjs — write state.json on bind · remove on SIGINT/SIGTERM · pid liveness + stale self-repair

Verify: node cli/bin.mjs ~/reports — curl /, raw page, traversal 403, bad escape 400
