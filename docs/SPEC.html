SPECIFICATION

docserve Spec

Serves a folder of HTML as a card gallery with live reload.

Overview

docserve ~/reports serves every HTML file in the folder as a card gallery.

Gallery

Card grid, iframe previews, copy-path button.

Auto reload

Add, edit, and delete are pushed to open tabs via WebSocket.

Desktop & CLI

Control it from the menu bar or the terminal.

Zero dependencies

Node stdlib only (http / fs.watch / crypto). No npm install.

Architecture

A single Node process serves the gallery, the pages, and the reload socket. The desktop app only spawns and monitors it.

Runtime state

Each instance writes its own ~/.cache/docserve/state/<port>-<name>.json (e.g. 4242-reports.json; name = sanitized folder name) once the port is bound and removes it on clean shutdown. Readers verify the PID is alive (kill(pid, 0)) and prune dead-PID files in place; DOCSERVE_STATE_DIR overrides the state dir.

FieldTypeDescription
pidnumberServer process. stop sends SIGTERM to it; liveness-checked before use
portnumberActually bound port (starts at 4242, falls back +1 on conflict)
urlstringhttp://localhost:<port>/
docsDirstringAbsolute path of the serving folder
One instance per folder: starting with the same docsDir while its server runs just points at its URL (opens the browser with --open, prints it otherwise). A different docsDir starts its own instance — one process (and one port) per folder; on a port conflict the port falls back +1.

CLI

Syntax: docserve [dir] [command] [options]

Argument / CommandBehavior
[dir]Folder to serve (default: .). Errors with exit 1 if it does not exist
(none)Foreground start. Ctrl+C stops that instance and removes its state file
stopStop the server serving [dir], or every instance when [dir] is omitted. Stale state (dead pid) is pruned silently
statusList every running instance (url + docsDir); exit 1 when none
--openOpen the gallery in the browser once the port is bound
--port <n>Port to bind (default 4242). On conflict, falls back +1 up to 20 tries and records the bound port in the instance's state file
--backgroundStart detached; the bound port and pid land in the state dir
-h / -vShow help / version

Serving

The gallery is an embedded template served at /; every other file is served raw from docsDir.

URLResponse
/, /index.htmlEmbedded gallery template. Card list is fetched from /api/files; docsDir/index.html is excluded
/api/filesJSON list: title, url (docsDir-relative link), path (absolute), created, modified, favicon (resolved <link rel="icon"> URL, omitted when unset) per *.html
/foo.html, /sub/bar.htmlRaw file from docsDir; nesting preserved
any other pathAny extension, MIME by extension with application/octet-stream fallback

Malformed paths respond 400, paths escaping docsDir respond 403, missing files respond 404. text/html responses get the reload client injected (see Injection). The server binds 127.0.0.1 only.

Gallery

The gallery lists every *.html under docsDir (recursive, excluding index.html), sorted by created date, newest first. The card list is fetched from /api/files on load.

CardSource
TitlePage <title>, falling back to the file name
FaviconPage <link rel="icon">, shown before the title; hidden when unset
Preview<iframe> of the page, lazy-loaded
Created / ModifiedDate resolution below
Copy pathAbsolute file path to the clipboard

Dates: <meta name="created_at"> > oldest git commit date > file birthtime. Lazy previews: IntersectionObserver with rootMargin: 400px, at most 3 iframes loading at once.

Reload protocol

Open tabs stay current through a WebSocket at /__reload. File events are batched for 50 ms and broadcast as one message. 

{ "type": "change", "pages": ["foo.html", "sub/bar.html"], "contentSetChanged": false, "templateChanged": false }

pages holds the docsDir-relative paths touched in the batch; contentSetChanged is true when a file was added or removed; templateChanged is true when the gallery template itself was edited.

ClientReloads when
Page tabIts own path appears in pages
Gallery tabcontentSetChanged or templateChanged is true
iframe previewNever connects — the window.self !== window.top guard keeps edits from reloading previews

Detection is a single fs.watch(docsDir, { recursive: true }) filtered to *.html. On socket close, page tabs reload after 1 s and recover once the server is back.

Injection

Every text/html response gets one client script before the last </body> (appended at the end if the tag is missing). The script exits immediately inside iframes, so previews get neither part; the gallery template ships its own client.

InjectedBehavior
Reload clientConnects to /__reload and follows the Reload protocol
Copy path buttonFixed at the top-right with a "Copy file path" label; copies the file's absolute path and shows "Copied" for 1.2 s

pageId and the absolute path are embedded JSON-encoded, with < escaped to \u003c so page content cannot break out of the client.

Desktop app

A macOS menu bar client with zero windows — the Electron main process only spawns the CLI and watches the CLI's state files (fs.watch + 2 s polling, pid liveness check).
