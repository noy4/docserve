FEATURE SPEC · EXTERNAL CSS DONE

CSS auto-reload

Reload a page's styles when a linked .css file changes — without a full page reload.

Scope

One feature, two levels. External stylesheets ship; inline styles are under consideration.

External CSS

DONE

Editing a linked .css refreshes <link rel="stylesheet"> in place — no page reload, state preserved.

Inline <style>

CONSIDER

Editing the <style> inside a standalone HTML swaps only the stylesheet text. Design open — see Roadmap.

Detection

Extends the existing fs.watch to *.css; batched and broadcast like HTML changes.

Zero dependency

Node stdlib plus browser fetch / DOMParser only. No npm install.

Detection & protocol

The server is the only change: the client keeps the same socket and adds one message branch.

Watched extensions

ExtensionMessageBehavior
.htmlchangeUnchanged — existing page/gallery reload rules still apply
.csscssNew — batched for 50 ms like HTML, broadcast as one message

shouldIgnore() applies to both: dot-prefixed paths and node_modules never broadcast.

css message

{
  "type": "css",
  "files": ["styles/main.css", "theme/dark.css"]   // docsDir-relative paths touched in the batch
}

`files` is informational; the client refreshes its stylesheets regardless of which file changed.

.css change → css message → linked sheets refreshed in place

Client behavior

External stylesheets DONE

On type === "css", each same-origin stylesheet link gets a fresh cache-busting href. 

function refreshStylesheets() {
  for (const link of document.querySelectorAll('link[rel="stylesheet"]')) {
    const url = new URL(link.href, location.href)
    if (url.origin !== location.origin) continue   // skip CDN / cross-origin
    url.searchParams.set("_cacheOverride", Date.now().toString())
    link.href = url.toString()                     // re-fetch, re-apply, keep state
  }
}

Page tab

Subscribes to css and calls refreshStylesheets().

Gallery tab

Has no external stylesheet today; ignores css.

iframe preview

Never connects (window.self !== window.top) — unaffected.

Inline <style> CONSIDER

Under consideration. Not scheduled. Standalone HTML is docserve's primary content, so a style-only swap is valuable — but the design is still open and shipped separately from the external-CSS work.

Candidate design: when a page's own HTML changes, fetch it and swap only if the structure is untouched. 

// on type:"change" where pages includes this pageId
const newDoc = new DOMParser().parseFromString(await (await fetch(location.href, { cache: "no-store" })).text(), "text/html")
// ignore the injected client on both sides, then compare
if (bodyEqualIgnoringClient(document, newDoc) && stylesDiffer(document, newDoc)) {
  swapStyleText(document, newDoc)   // scroll + form state preserved
} else {
  location.reload()                 // structure changed → safe fallback
}

Non-goals & edge cases

Not watched

  • .js and other assets
  • CSS @import sub-resources
  • Cross-origin / CDN sheets

Safety

  • Same-origin links only — CDNs are not cache-busted
  • Server stays bound to 127.0.0.1
  • No ETag / 304 (still out of scope)

Add / remove

A .css add or delete broadcasts css too; an unlinked file simply changes nothing on the page.

No double reload

css and change stay separate messages — a stylesheet edit never flips contentSetChanged.

Acceptance criteria

#Criterion
1Editing a linked .css updates the page with no full reload; scroll and form state are preserved
2Cross-origin stylesheet links are not rewritten
3Editing an .html still emits type:"change" with unchanged behavior
4A .css under .git / node_modules / dot dirs broadcasts nothing
5Two .css edits within 50 ms arrive as one css message
6No new runtime dependencies

R1 · Watch & broadcast

Extend the watcher to CSS

DONE
  • In the fs.watch callback, accept .css alongside .html
  • Route .css events to a dedicated debounce queue so they never mix into the change batch
  • Broadcast { type: "css", files: [...] }; keep shouldIgnore() and the docsDir boundary check
  • Acceptance: criteria 3–5

R2 · Client refresh

Refresh linked stylesheets

DONE
  • Handle type === "css" in the injected client's message listener
  • refreshStylesheets() rewrites same-origin link[rel="stylesheet"] hrefs with ?_cacheOverride=<now>
  • Skip cross-origin, data:, and non-stylesheet links
  • Leave the existing page-reload rule for pages.includes(pageId) untouched
  • Acceptance: criteria 1–2
