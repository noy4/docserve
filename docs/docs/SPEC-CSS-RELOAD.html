DESIGN NOTE · R1–R4 SHIPPED

CSS auto-reload

Why stylesheet edits refresh in place instead of reloading the page.

Scope

Protocol and client behavior live in SPEC.html; this note records the decisions behind them.

External CSS

SHIPPED

Editing a linked .css refreshes <link rel="stylesheet"> in place — no reload, state preserved.

Inline <style>

CONSIDER

Style-only swaps for standalone HTML. Design open — see Roadmap.

Decisions

DecisionRationale
Separate css message change carries gallery state (contentSetChanged) and mutates the known-file set; a stylesheet edit must not touch either.
Separate debounce queue Keeps each broadcast single-purpose: change is stateful, css is stateless. Batching is 50 ms for both.
Refresh same-origin <link> only Appending a cache-busting query to a CDN link would re-download needlessly; data: and cross-origin are skipped.
Inline <style> deferred Needs a body-equality comparison and an injected-client marker before it is safe — tracked as R5.

Not covered

  • Other assets — .js and images are not watched.
  • CSS @import sub-resources are not tracked; only the file itself is refreshed.
  • HTTP caching — no ETag / 304; each request re-sends the body.

R5 · Implementation notes

Not scheduled. Standalone HTML is docserve's primary content, so a style-only swap is valuable — but the design is still open.

Client sketch — try a style-only swap before falling back to location.reload(). 

// inject.html: on type:"change" when pages includes this pageId
async function tryInlineStyleHotSwap() {
  const res = await fetch(location.href, { cache: "no-store" })
  const next = new DOMParser().parseFromString(await res.text(), "text/html")

  const here = stripInjected(document.cloneNode(true))
  const there = stripInjected(next)
  if (here.body.innerHTML !== there.body.innerHTML) return false  // structure changed

  const mine = here.querySelectorAll("style")
  const theirs = there.querySelectorAll("style")
  if (mine.length !== theirs.length) return false                // style count changed
  for (let i = 0; i < mine.length; i++) mine[i].textContent = theirs[i].textContent
  return true                                                    // no reload, state kept
}

The live DOM carries runtime nodes the fetched copy lacks — the injected script, the copy button, and its <style>. Exclude all three before comparing. 

// strip runtime nodes from both documents before comparing
function stripInjected(doc) {
  for (const sel of ["#__docserve-client", "#docserve-copy", "#docserve-copy-style"]) {
    doc.querySelectorAll(sel).forEach((node) => node.remove())
  }
  return doc
}

Only #docserve-copy exists today; the other two markers must be added when R5 starts.

  • #__docserve-client — id on the injected <script> (in inject.mjs / inject.html).
  • #docserve-copy-style — id on the client's dynamically created <style>.

R5 · Open questions

  • Confirm innerHTML equality is strict enough (whitespace, attribute order).
  • Multiple <style> tags: match by index only when counts agree, else reload.
  • Head-only diffs other than <style> (meta, title): swap or force reload?
  • Decision gate: build only if style-only edits prove common in real docs.
