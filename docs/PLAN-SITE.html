HOMEPAGE PLAN

docserve Site Plan

Homepage & GitHub Pages publishing roadmap.

Overview

Publish the product homepage on GitHub Pages. The site serves under the /docserve/ subpath — every link must be relative.

DecisionValue
URLhttps://noy4.github.io/docserve/ — repo is public, so free Pages works
Pages sourceDeploy from branch: main / /docs. No Actions, no gh-pages branch, zero build
Filesdocs/index.html (new homepage) + SPEC.html / PLAN.html moved into docs/; local.* scratch stays at root, unpublished
DesignReuse the SPEC.html tokens — CSS variables, Geist Mono, iconify MDI, auto light/dark, single static file
Deploys: first publish takes 1–2 minutes; every push to main redeploys automatically. Jekyll processes the folder but plain HTML passes through untouched — no .nojekyll needed.
